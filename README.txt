Codex Speed 1.1.3
==============

一个原生 macOS 菜单栏工具，用于监测本机 Codex 会话的平均输出速度。
支持 Apple Silicon 与 Intel，macOS 13 或更新版本。

使用
----
双击 Codex Speed.app。程序不显示 Dock 图标，直接出现在顶部菜单栏。
上行：Σ 所有活动聊天的速度合计，单位 tok/s。
下行：当前 所选会话的速度，单位 tok/s。
“计入子 agent”开关同时控制两行速度及 token 合计，默认开启并记住选择。
点击菜单栏读数可打开详情；点击图钉可固定为悬浮侧栏，并拖动位置。
打开时在菜单栏读数下方展开详情，自动适配当前显示器的可见范围。
内容增加时面板位置和高度保持稳定；较小屏幕可以滚动查看内容。
点击图钉固定为侧栏时保持当前位置；收起后仍保留菜单栏读数。
右键菜单栏读数可退出。详情右上角菜单可以切换日志文件夹、导出 CSV。
如需长期使用，可以将 app 拖入“应用程序”后再打开。
本地构建使用临时签名，没有 Apple Developer ID 或 Apple 公证。


1.1.3：从全部统计排除自动审核
------------------------
实时和每日历史共用“计入 Codex auto review”开关，默认关闭并记住选择。
按请求记录中的 codex-auto-review 模型标识（含连字符后缀版本）排除自动审核用量；不会按聊天或 agent 昵称猜测。
排除后每日输入、输出、推理、缓存、均速、模型列表及费用覆盖同步调整，并显示排除的输入、输出和调用数。
只含 auto review 的日期仍可选择；重新开启即可恢复，不修改日志。
此开关独立于“计入子 agent”，同时控制两行实时速度、活动数、本轮与会话合计、每日历史和 CSV 导出。
子 agent 明细保留原始记录，并标注排除状态。混合模型按每次请求过滤；必要的历史日志在后台分批补读。

1.1.1：减少后台开销
------------------
相关日志变化通过系统文件通知触发刷新；空闲且面板关闭时，定时检查改为 30 秒一次。
有活动会话或面板可见时约每秒刷新；通知不可用时保留每秒轮询。
关闭面板后暂停自动扫描每日历史，重新打开时补全。
缓存语言资源、未变化的会话标题和每轮聚合结果；菜单栏数字未变化时不重绘。
元数据发现不再解析无用时间戳，日期解析器按需创建，子 agent 按所属会话一次分组。
新文件、旧聊天与旧子 agent 恢复活动时及时重新发现；系统唤醒后补扫。
性能复现方式见 docs/PERFORMANCE.md 和 scripts/benchmark.sh。

1.1.0：中英文界面
----------------
默认跟随 macOS 的首选语言，支持简体中文和英文；其他语言回退到英文。
点击详情右上角“…” →“语言”，可选“跟随系统 / 简体中文 / English”。
切换后立即更新菜单栏、详情、每日历史、费用说明及提示，并记住选择。
聊天标题、自定义 agent 名称、模型标识和 CSV 列名保留原文；语言不会改变统计或费用计算。
英文使用说明见 README.md。

1.0.9：识别 Standard / Fast 与分档估价
--------------------------------------
实时详情展示主 agent 的最新模式设置，子 agent 明细分别展示各自的模式。
从本机日志 thread_settings_applied.thread_settings.service_tier 读取设置；
default / standard 识别为 Standard，priority / fast 识别为 Fast。
也兼容 turn_context 中明确记录的 service_tier，不从当前全局配置倒推历史模式。

每日与各模型统计显示 Standard、Fast、未知或未支持模式的调用次数。
按每次调用输出起点对应的设置估价；没有输出起点时，只使用本轮起点或上一调用边界已知的模式。
同一轮中途切换模式不会重算此前已记录调用，输出中途更改设置也不会改变该段的模式。
主 agent 与子 agent 按各自日志计价；关闭子 agent 后相应调用与费用不计入合计。
目前价格表中的四个模型，Fast 的输入、缓存读取、缓存写入及输出均按 Standard 的 2 倍。
长上下文加价与 Fast 倍数叠加，仍逐次调用计算。
没有模式记录、auto 或尚未支持的档位均不默认成 Standard，也不计入估价；token 总量仍保留。

日志中的设置并不确认服务端实际使用的档位，Fast 请求有可能被降级。
因此费用标为“按日志设置估价”，不等同实际 API 账单，更不代表订阅扣款。
Fast 参考：https://developers.openai.com/api/docs/guides/fast-mode

1.0.8：API 等价费用估算
----------------------
每日历史新增当日与各模型的 API 等价费用（美元），历史日期列表也显示费用。
按 2026-10-15 核对的 OpenAI Standard 基价及 Fast 倍数回算历史，不代表 ChatGPT/Codex 订阅实际扣款。
仅估算模型 token 费用；未加入工具单独收费、税费和地区调整。其他服务模式暂不估价。
当前价格表包含 gpt-6-astra、gpt-6.1-sol、gpt-6-sol、gpt-6-luna，面板可展开查看官方价格链接。

每次请求分别计算：
未缓存输入 = 输入总量 - 缓存读取 - 缓存写入。
费用 = 未缓存输入 × 输入单价 + 缓存读取 × 缓存单价 + 缓存写入 × 写入单价 + 输出 × 输出单价。
单价单位为美元/百万 token。缓存读写是输入的不同组成部分，不重复收费；推理已含在输出内。
单次输入超过 272,000 token 时，该次全部输入和缓存单价翻倍，输出单价乘 1.5。
不会把一天所有请求的输入合在一起判断长上下文。

没有已知模式、公开价格（例如 codex-auto-review），或缺少输入/输出/缓存读取/缓存写入分项的请求，不计入金额。
页面标注估价覆盖次数；存在未估价请求时，总金额显示“已定价部分”，不会当作零费用。
模型上下文晚到时会回填并重新归价；重复记录、父历史复制及双格式日志不会重复计费。
费用统计沿用“计入子 agent”开关。无需 API Key，也不会发送 API 请求或产生实际收费。

价格参考：
https://developers.openai.com/api/docs/pricing

1.0.7：每日统计与历史记录
-------------------------
面板顶部切换“实时速度 / 每日历史”。菜单栏仍保持全局总速和当前会话速度两行。
每日历史覆盖日志目录中所有独立聊天及已归档聊天，不受实时最近聊天列表限制。
“计入子 agent”开关控制每日统计是否包含子 agent，历史已完成的调用也计入每日用量。
选择日期或展开“历史记录”，可查看各天输入、输出、推理、缓存命中和平均输出速度。
每个日期同时展示各模型的输入/输出、缓存命中、调用次数与平均速度。

日期按本机时区划分，页面标注实际时区；每次调用归入用量记录写入的日期。
逐次请求用量只计一次；不会把轮次/线程累计量重复加进每天。
缓存命中率 = 有记录的缓存命中输入 token ÷ 相应请求的输入 token。
缓存命中的 token 已包含在输入总量内。缺少缓存字段的请求不当作零命中，页面显示缓存覆盖次数。
平均速度固定采用连续输出估算 = 有效输出 token 合计 ÷ 对应输出时间合计。
排除首段前等待与已记录工具执行；含推理与工具参数。多个 agent 的输出时间分别相加。
缺少可靠起止时间的调用保留输入/输出总量，但不参与速度，页面显示计时覆盖次数。
没有有效速度或缓存数据时显示“—”。不同模型/不同天的速度不可直接做算术平均。

首次查看时在后台分批读取完整日志，会显示读取进度；加载期间当前合计可能尚未完整。
历史统计只在内存中构建，退出后不额外保存聊天正文、用量数据库或缓存文件。
再次打开可从仍保留的本机日志重建；被删除、未同步的远程或云端日志无法补回。

1.0.6：全局与当前会话两行速度
---------------------------------
菜单栏上行：Σ = 所有本机活动聊天的速度合计。
菜单栏下行：当前 = 面板“当前会话”所选聊天的速度。
启用“计入子 agent”时，各聊天速度包含主 agent 及所有活动子 agent 的速度之和；关闭时只计主 agent。
当前会话在面板选择；“最近活动（自动）”会自动跟随，无法识别 Codex 窗口当前选中的聊天。
只有尚未完成且最近 5 分钟有日志变化的 agent 参与速度；没有有效样本时显示“—”。
每个 agent 各自计时，跨 agent 并行速度直接相加，不把并行时间串成一条时间线。
所选会话没有活动时，下行显示“—”；其他活动聊天仍可影响上行。
显示的是日志样本估算，不是逐 token 瞬时解码速度。

子 agent 数量与明细：
“活动子 agent”只显示当前活动数量，包括工具等待中且仍符合上述活动判据的子 agent。
明细保留所有子 agent，展示每个 agent 的速度、累计输入、累计输出、模型及状态。
活动中的标为“本轮速度”，已结束或空闲的标为“最近速度”，均使用所选统计口径。
日志正在读取或没有有效样本时显示“—”；新一轮不沿用上一轮速度。
关闭“计入子 agent”后，仍可以查看它们的活动数量和明细，但不加入统计合计。

所选聊天的 token：
启用子 agent 时，本轮合计按明确的主轮或父轮关联，包含该轮启动或续接的子 agent。
会话累计按每个线程最后的累计用量加总，包含历史轮次、已停止及已归档的子 agent。
关闭子 agent 时，本轮、累计、最近完成输出和 CSV 导出均只计算主 agent；历史数据仍保留。
每个线程只加一次；复制的父历史、重复文件和独立分叉聊天不混入。
具有明确父会话关联的内部审核助手也计入；无法确认归属的后台任务不计入。
输入 token 是所有请求的累计输入，包含重复上下文；推理 token 已包含在输出里。
部分日志未读取完或缺少累计字段时显示提示。
只统计本机可读日志；缺失的云端或远程主机日志仍无法计入。

统计口径
--------
默认使用“连续输出（估算）”，也保留“扣工具（估算）”与“整轮均速”。
升级到 1.0.4 时自动选择新口径一次；之后记住手动选择。

连续输出（估算）：
逐次模型调用匹配输出 token 和对应输出时段，合计 token ÷ 合计输出时间。
每段起点取该次调用最早的 Reasoning / AgentMessage / Plan 项目开始时间。
终点取该次调用最后一个已完成模型输出项目的时间，包括模型生成的工具调用参数。
不计每次输出之前的等待、段间工具执行、最终输出到用量统计落盘之间的等待。
段内已记录工具时间取并集扣除；已知模型生成与后台工具重叠时保留生成时间。
每次调用只有用量而没有可靠起点时，连同它的 token 一起跳过。
主 agent 的有效调用数与输出时间在所选会话详情中展示；全局速度区标注有有效速度样本的 agent 数量。
详情中的本轮与最近完成输出遵循“计入子 agent”开关；速度只统计当前范围中各活动 agent 的有效样本。
本轮开始记录被截断时，首个不完整调用跳过，后续完整调用可以恢复统计。
计时不到 0.1 秒或有异常记录的调用跳过，缺少有效样本时显示“—”。
含推理、回答、工具调用参数等模型输出，不等于屏幕文字的显示速度。
这是基于输出项目边界的估算：日志不记录逐 token 到达时间，项目开始通常略早于首个 token。
不能精确测量服务器纯解码速度；输出期间的网络停顿仍可能影响读数。

首字延迟（估算）：
从本轮开始，到首段可见 AgentMessage 的日志起点，不把 Reasoning 当作可见文字。
在日志记录到达后更新（通常是该段文字结束后），并非逐字即时采样。
缺少本轮起点或可见文字记录时说明暂无数据，不用其他时间填充。
“首 token 延迟（日志）”来自 Codex 完成事件里的 time_to_first_token_ms，可能是推理输出。
两个延迟单独展示，不追加到连续输出模式的分母。

扣工具（估算）：
本轮已统计输出 ÷（截至最近统计的耗时－已记录工具区间并集）。
并行和嵌套工具不重复扣除，保留与已知模型生成重叠的时间。
仍包含网络、输入处理和每次调用前的等待，不是连续输出模式。
本轮较早时间记录不完整时显示“—”。

整轮均速：
本轮已经统计的输出 token ÷ 从本轮开始到现在的耗时，含工具和等待。
完成后使用日志记录的本轮耗时，读数固定；新一轮重新统计。

所有模式的 token 数均在模型调用结束时更新，不是逐 token 的瞬时测速。
推理 token 已包含在输出 token 中，不能再次相加。
图表记录全局速度合计，在有效统计更新时采样；应用打开之前的图表不重建。
超过 5 分钟没有日志写入且缺少完成事件时显示“暂无活动”和“—”。

会话与日志
----------
默认日志位置为 ~/.codex/sessions，支持 CODEX_HOME 环境变量或手动选择目录。
详情默认自动跟随最近活动的本地会话；也可固定选择。列表保留最近 8 个聊天、所有活跃聊天和已固定的聊天。
会话选择器显示 Codex 中的真实聊天标题，不再显示目录名或 ID。
读取日志目录旁的本地标题数据库和 session_index.jsonl，标题重命名后自动刷新。
主聊天列表过滤后台内部任务；子 agent 合并到所属主聊天，可展开查看明细。
单独复制的日志若没有标题元数据，会显示“未命名会话”。
它无法获知 Codex 窗口当前选中了哪个聊天，请用会话选择器固定需要的会话。
每秒增量读取，每 10 秒发现新会话。大型主聊天日志读取元数据及末尾 8 MiB；子 agent 分批从头读取以保留同一主轮下的多次调用。
若本轮起点不在末尾数据中，会等下一轮，或在完成后用官方时长恢复统计。
远程 SSH 主机和云端会话的日志未同步至本机时，无法读取这些会话。
Codex 聊天链接只用于定位会话，不包含 token 或模型计时数据。
能看到云端聊天内容、状态和工具时长，也不足以计算真实 tok/s。
详情菜单中的“为什么看不到云端会话…”可查看原因。
兼容 token_usage_record 和旧版 token_count，避免两种格式并存时重复计数。
Codex 日志格式不是稳定公共接口；将来升级 Codex 后可能需要更新解析器。

隐私
----
程序没有网络请求，不需要 API Key，不读取 auth.json，不修改 Codex 配置。
只将 token 数、耗时、模型、会话标题和位置等统计保存在内存中。
标题数据库仅以只读方式打开。
不会保存提示词或工具输出，也不会上传日志。
CSV 按“计入子 agent”开关导出所选聊天的已读轮次及累计，不含聊天内容。row_scope 区分 agent_turn、agent_lifetime、family_lifetime；不同层级不要再次相加。
包括各口径速度、实际计入的输出与时长、覆盖调用数、首字估算延迟、首 token 日志延迟。
可以随时退出并删除 app。

源码与重建
----------
安装 Xcode 或 Apple Command Line Tools 后，在源码目录执行：
  swift test
  bash build.sh
生成的通用 app 位于 dist/Codex Speed.app。
build.sh 也支持传入自定义输出目录作为第一个参数。
没有第三方依赖。使用 AppKit、SwiftUI、Foundation 和 macOS 自带的 SQLite。
