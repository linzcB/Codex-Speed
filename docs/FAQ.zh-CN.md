# 常见问题

[English](FAQ.md) · [返回首页](../README.zh-CN.md)

### 找不到主窗口？

这是菜单栏应用，没有 Dock 图标。点击顶部两行读数查看详情，点击图钉可保持悬浮侧栏；右键读数可打开包含“退出”的菜单。

### 为什么没有云端会话？

需要本机 session 日志中的逐次请求用量和计时。下载的工作目录、聊天正文或账号总用量不能代替这些记录，详见[数据覆盖](STATISTICS.zh-CN.md#数据覆盖)。

### 为什么与 Codex 账号统计不同？

本工具只统计可读取的本机日志，账号总量可能覆盖其他主机或云端聊天。首次加载、未知模式、缺少计时或费用分项也会带来差异。对比时应统一日期、时区、会话、子 agent 开关及 token 类别。

### 能跟随 Codex 窗口当前选中的聊天吗？

请在面板中选择会话。自动模式跟随最近日志活动，不读取 Codex 窗口的选中状态。

### 关闭子 agent 统计后还能看明细吗？

可以。明细继续保留，但它们的速度、token、每日用量和费用不会计入所选合计。

### API 估算是我的真实账单吗？

不是。它按已支持的公开价格和日志设置估算 API 等价金额，未知或数据不完整的调用不计价。它不代表订阅扣款，也不能确认服务端实际计费档位。

### 为什么 macOS 阻止打开？

当前构建使用临时签名，没有 Apple 公证。请先核对源码、发布校验文件及 [Apple 官方说明](https://support.apple.com/guide/mac-help/mh40616/mac)，再决定是否允许运行。项目不要求关闭系统级安全保护。

### 如何切换语言？

点击 **… → 语言**，可选择跟随系统、简体中文或 English，并记住选择。聊天标题与自定义 agent 名称保留原文。
