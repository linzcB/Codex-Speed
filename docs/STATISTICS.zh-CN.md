# 统计口径

[English](STATISTICS.md) · [返回首页](../README.zh-CN.md)

## 实时速度

| 口径 | 计算方式 | 边界 |
| --- | --- | --- |
| 连续输出 | 有效输出 token ÷ 已记录的输出阶段时间 | 排除输出前等待和段间工具执行，包含推理与生成的工具参数；日志起点未精确到首个 token。 |
| 扣工具 | 已统计输出 ÷ 扣除已记录工具执行后的本轮时间 | 仍包含网络、输入处理等等待。 |
| 整轮均速 | 已统计输出 ÷ 本轮耗时 | 包含工具与等待。 |

菜单栏上行汇总全部活动聊天，下行展示面板中选择的会话。启用子 agent 时，每个 agent 分别计时，有有效样本的实时速度相加。

“活动”指最新一轮尚未结束，且最近 **5 分钟**有日志更新。没有有效计时的 agent 不贡献速度样本。“—”表示没有足够样本，不代表输出为零。启用子 agent 后，已结束子 agent 的历史 token 仍可计入累计。

## 延迟

- **首字延迟（估算）：** 从本轮开始到首段可见回答日志的起点，不把推理当作可见文字。
- **首 token 延迟（日志）：** Codex 在整轮结束时写入的 `time_to_first_token`；可能指推理输出，所以与首字延迟不一定相同。

## 每日历史

按用量记录的日期和界面标注的本机时区归日，包含独立聊天、开启统计时的子 agent 以及本机归档聊天。逐次请求只计一次，不重复相加复制的父历史或线程累计值。

**每日均速 = 有效输出 token 合计 ÷ 对应输出时间合计。** 并行 agent 的时间分别相加，因此该指标与实时速度合计不同，也不是将各个显示速度直接求算术平均。缺少可靠计时的调用保留用量，但不参与均速。

**缓存命中率 = 命中输入 token ÷ 有缓存记录的调用输入 token。** 命中的 token 已包含在输入中；缺失缓存字段不当作零命中。界面同时显示缓存与计时覆盖次数。

## 费用估算

按已支持的模型价格和每次请求日志中的 Standard / Fast 设置估算，并使用已支持的长上下文规则。每个 agent 使用自身的设置。未知模式、不支持的模型、分项缺失的请求不计价，界面标注已定价部分及覆盖率。

不会用最新设置重新计算旧调用的模式。日志设置无法确认服务端实际档位，也无法确认 Fast 是否被降级。结果不是订阅扣款或已确认的 API 账单。价格表核对日期和官方链接可在应用中查看。

## 数据覆盖

只读取本机日志。云端或远程日志未同步时，不能从聊天正文或工作目录还原用量和模型计时。首次扫描和末尾记录尚未写完可能暂时降低覆盖率，界面会显示相应提示。

切换界面语言时，聊天标题、模型标识、归日键和 CSV 列名保留原值。

## 排除自动审核用量

实时与每日历史共用“计入 Codex auto review”，默认关闭并记住选择。按每次请求的模型标识 `codex-auto-review` 和 `codex-auto-review-*` 识别，不根据聊天标题或 agent 昵称猜测。页面单独显示已排除的输入、输出和调用数；每日总量、缓存比例、加权均速、模型列表及费用覆盖的分母都使用筛选后的调用。只有排除项的日期仍可选择。

该开关同时控制两行实时速度、活动聊天与 agent 数、本轮及会话累计用量、CSV 导出。混合模型的轮次只保留计入请求及其对应的输出时间样本。明细保留原始记录并标注排除状态；当前正在运行 auto review 的 agent 不计入活动数，但它之前其他模型的用量仍保留在会话合计中。

子 agent 开关保持独立，不修改本机日志。为准确计算按模型筛选的累计值，缺失的日志前缀会在后台分批补读，并显示读取中或覆盖不完整提示；无法识别模型的请求保留计入。重新打开开关会恢复已记录用量；不会为模型添加价格或确认计费状态。

## 预计每小时 API 费用

实时页面按“最近 N 分钟内计入请求的 API 等价费用 ÷（N × 60）× 3600”估算 USD/h。N 可选 1、5、15 分钟，默认 5 分钟并记住选择。复用已有价格快照，计入输入、缓存读取/写入、输出及每次请求的 Standard/Fast 设置。它假设之后保持相同使用强度，不是已确认的实际账单。

分母为完整的自然时间窗口，包含等待和工具执行。已完成及归档聊天的请求，只要仍在窗口内就计入，不受实时聊天选择器最近八个会话的限制。全局按独立线程去重；当前会话在启用子 agent 时加上明确归属的子会话。子 agent 和 auto review 开关均按请求生效。

按用量完成记录的时间纳入窗口，未结束请求在用量记录出现前暂不计入，因此数字可能分段更新。只纳入 `(当前时间 − 窗口, 当前时间]` 内的记录。完整窗口没有调用时显示零；有调用但价格、模式或缓存分项不足时显示未计价，不当成免费。页面显示估价覆盖率，读取日志时等待，发现缺口时标明只含已知部分。云端没有同步到本地的日志仍无法统计。

此功能仅保留最近 15 分钟的数值费用摘要，并在扫描时清理过期记录；复用实时增量读取，不会为了费用卡片另启一次完整每日历史扫描。选择连续吐字或扣除工具等速度口径，不会改变费用观察窗口的分母。
