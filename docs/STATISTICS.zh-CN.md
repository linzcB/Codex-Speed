# 统计口径

[English](STATISTICS.md) · [返回首页](../README.zh-CN.md)

## 实时速度

| 口径 | 计算方式 | 边界 |
| --- | --- | --- |
| 连续输出 | 有效输出 token ÷ 已记录的输出阶段时间 | 排除输出前等待和段间工具执行，包含推理与生成的工具参数；日志起点未精确到首个 token。 |
| 扣工具 | 已统计输出 ÷ 扣除已记录工具执行后的本轮时间 | 仍包含网络、输入处理等等待。 |
| 整轮均速 | 已统计输出 ÷ 本轮耗时 | 包含工具与等待。 |

菜单栏上行汇总全部活动聊天，下行展示面板中选择的会话。启用子 agent 时，每个 agent 分别计时，有有效样本的实时速度相加。

“活动”指最新一轮尚未结束，且最近 **5 分钟**有日志更新。没有有效计时的 agent 不贡献速度样本。“—”表示没有足够样本，不代表输出为零。启用子 agent 后，已结束子 agent 的历史 token 仍可计入累计。

## 延迟

- **首字延迟（估算）：** 从本轮开始到首段可见回答日志的起点，不把推理当作可见文字。
- **首 token 延迟（日志）：** Codex 在整轮结束时写入的 `time_to_first_token`；可能指推理输出，所以与首字延迟不一定相同。

## 每日历史

按用量记录的日期和界面标注的本机时区归日，包含独立聊天、开启统计时的子 agent 以及本机归档聊天。逐次请求只计一次，不重复相加复制的父历史或线程累计值。

**每日均速 = 有效输出 token 合计 ÷ 对应输出时间合计。** 并行 agent 的时间分别相加，因此该指标与实时速度合计不同，也不是将各个显示速度直接求算术平均。缺少可靠计时的调用保留用量，但不参与均速。

**缓存命中率 = 命中输入 token ÷ 有缓存记录的调用输入 token。** 命中的 token 已包含在输入中；缺失缓存字段不当作零命中。界面同时显示缓存与计时覆盖次数。

## 费用估算

按已支持的模型价格和每次请求日志中的 Standard / Fast 设置估算，并使用已支持的长上下文规则。每个 agent 使用自身的设置。未知模式、不支持的模型、分项缺失的请求不计价，界面标注已定价部分及覆盖率。

不会用最新设置重新计算旧调用的模式。日志设置无法确认服务端实际档位，也无法确认 Fast 是否被降级。结果不是订阅扣款或已确认的 API 账单。价格表核对日期和官方链接可在应用中查看。

## 数据覆盖

只读取本机日志。云端或远程日志未同步时，不能从聊天正文或工作目录还原用量和模型计时。首次扫描和末尾记录尚未写完可能暂时降低覆盖率，界面会显示相应提示。

切换界面语言时，聊天标题、模型标识、归日键和 CSV 列名保留原值。
